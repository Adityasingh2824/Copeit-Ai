# Copeit shared official corpus

Status as of 1 November 2026: one independently reviewed CE-marking excerpt has been admitted. Ask Cope remains offline pending live acceptance tests. This excerpt is not a broad electronics corpus.

The private `copeit_private.shared_official_versions` allowlist controls which independently approved document versions can be searched across workspaces. Workspace-owned sources are never global merely because they have been uploaded or approved. Browser roles cannot read or modify the allowlist or call the privileged shared search.

Only an approved, fully processed `official_guidance` source without a product association, with an HTTPS canonical URL, an enabled admission, a documented licence decision and a future review date is searchable. Revocation, disabling, expiry or changing the source status immediately excludes it. Product facts remain tenant-scoped and are never stored in the shared corpus.

The reviewer confirmed the excerpt against the European Commission page and approved reuse with attribution under its CC BY 4.0 notice. The source's publication date is unknown; 1 November 2026 is its retrieval date, not a publication date. The admission is due for review on 1 December 2026. The excerpt is insufficient for a broad electronics corpus.

Before enabling live answers, a qualified reviewer must sign off source admission; operators must run live model-generated cited-answer and abstention evaluations, real two-tenant HTTP tests, source-revocation tests, monitoring and rollback checks. No approval is created by this infrastructure migration.
